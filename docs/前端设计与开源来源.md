# 前端改版与开源来源

本次改版采用 Tabler 1.5.0 作为真实组件依赖，替换原来的独立 Bootstrap 样式入口。Tabler 的 CSS 经本机 `/vendor/tabler/tabler.min.css` 提供，支持离线演示。业务页面、仓库空间图、状态统计及接口交互由本项目实现与适配。

## 参考与选型

|项目|GitHub|本项目使用情况|
|---|---|---|
|Tabler|https://github.com/tabler/tabler|采用 @tabler/core 1.5.0，使用按钮、表格、输入、卡片及主题基础样式|
|Flowbite Admin Dashboard|https://github.com/themesberg/flowbite-admin-dashboard|对比后台布局与信息密度，未复制其源码|
|CoreUI Free Bootstrap Admin Template|https://github.com/coreui/coreui-free-bootstrap-admin-template|对比导航与后台组件，未复制其源码|

Tabler 使用 MIT 许可证，许可证随项目保存在 `third-party/Tabler-LICENSE.txt`，原作者版权声明保留。来源核查日期为 2026年11月3日。仅采用开源版本组件，不依赖付费模板。

## 改版内容

- 重组应用外壳，采用白色侧导航、蓝色主动作、灰蓝工作区与层次分明的数据卡片。
- 总览采用等距 SVG 仓库空间图，可切换 A、B、C 分区，点击货位查看实际批次。该图为布局示意，不作为实际测绘或拣货路径。
- 履约环形图与进度条按数据库订单状态统计，冷链曲线来自实际模拟采样记录。
- 改进表格、筛选、表单、弹层、物流时间线、事件流、验证结果及登录页。
- 支持明暗主题切换与本机偏好保存；提供商品全局搜索及斜杠快捷键。
- 窄屏采用折叠导航、纵向卡片和可横向滚动的数据表格。

## 文件与职责

`public/theme.css` 为项目视觉主题；`public/warehouse-scene.js` 为自绘仓库视图；`public/app.js` 保留领域命令与接口交互，并重写页面表现结构。库存事务、预留、取消、事件消费等业务逻辑没有因前端改版而重写。
