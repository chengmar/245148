# 接口与部署说明

基础地址 http://localhost:3210。服务默认只监听127.0.0.1；所有业务接口使用 JSON。账号与角色见 README。

## 会话与命令

POST /api/login 请求 `{"username":"admin","password":"WareFlow2026!"}`。响应设置 `wf_session`，HttpOnly、SameSite Strict，8小时有效。可通过 GET /api/me 查看当前角色，POST /api/logout 注销。公开健康检查 GET /api/health 返回数据库驱动与版本。

写业务命令需传 `Idempotency-Key: <8至64字符>`，推荐 UUID。同用户同资源同操作同载荷重试返回原响应，复用键却更改载荷返回409。请求对象序列化后的字段顺序参与指纹，因此重试应原样发送。

|接口|请求关键字段|正常结果|
|---|---|---|
|POST /api/receipts|product_id location_id batch expiry quantity supplier|入库单与批次号|
|POST /api/orders|customer destination priority lines|订单号与CREATED|
|POST /api/orders/:id/reserve|空对象|RESERVED|
|POST /api/orders/:id/pick|空对象|PICKED|
|POST /api/orders/:id/ship|空对象|SHIPPED|
|POST /api/orders/:id/cancel|空对象|CANCELLED|
|GET /api/orders/:id/route|无|points distance baseline saved method|
|POST /api/counts|lot_id counted version reason|盘点差异|
|POST /api/readings|temperature device_id可选默认COLD-01|采样值与告警ID|
|POST /api/alerts/:id/resolve|空对象|RESOLVED|
|POST /api/shipments/:id/tracking|status message|运单新状态|
|GET /api/state|无|业务一致快照|
|GET /api/reconcile|无|ok 批次数 事件数 差异明细|
|POST /api/events/worker|paused布尔值|暂停状态|
|POST /api/events/dispatch|fail布尔值|成功数与失败数|
|POST /api/events/:id/retry|空对象|死信进入RETRY|

示例订单行 `"lines":[{"product_id":"SKU-001","qty":10}]`。物流回调状态必须为下一合法状态；签收之前必须先IN_TRANSIT。同一回调的幂等键防止重复轨迹。

## 环境变量

|变量|默认值|用途|
|---|---|---|
|PORT|3210|HTTP端口|
|HOST|127.0.0.1|监听地址|
|DB_DRIVER|sqlite|sqlite或mysql|
|SQLITE_PATH|data/wareflow.db|SQLite持久化文件|
|MYSQL_HOST|127.0.0.1|MySQL主机|
|MYSQL_PORT|3306|MySQL端口|
|MYSQL_DATABASE|wareflow|业务库；测试须为*_test|
|MYSQL_USER|wareflow|数据库账号|
|MYSQL_PASSWORD|wareflow_lab_2026|课程环境默认密码|
|COOKIE_SECURE|未设置|设置1后会话Cookie仅通过HTTPS|
|WORKER_DISABLED|未设置|设置1停用自动消费者，用于手动演练|

应用首次空库启动时自动创建表并初始化演示数据；已有商品数据则跳过初始化。请保留完整数据库，不要单独删某些主数据再期待自动补齐。幂等和事件记录当前没有自动保留期限，应随数据库一起备份。

## 部署与恢复

便携模式 `npm install --ignore-scripts` 后 `npm start`。Windows提供启动脚本；当前电脑可使用已配置Node路径，其他电脑优先安装Node.js24官方发行版。

MySQL容器模式 `docker compose up --build -d`。MySQL数据存储在命名卷中；停止使用 `docker compose down`，不要随意加 `-v`，因为那会移除持久化卷。健康检查 `http://localhost:3210/api/health`，数据库检查与应用日志 `docker compose logs app`。

SQLite备份在停服后复制整个data目录。MySQL使用一致性备份工具并保留Outbox、流水和幂等表；恢复后登录并运行完整校验，再验证一笔端到端业务。禁止在真实业务库上运行测试清理脚本。

当前电脑未安装Docker CLI，Compose未在本机执行；MySQL适配通过GitHub Actions服务环境验证。对外开放前需去除演示账号、配置HTTPS和独立设备身份、修改默认数据库密码并实施日志保留策略。
