# 前端改版验收记录

验收日期 2026年11月4日。执行主体为 Codex 浏览器工具与自动化测试程序，不作为学生人工审查签字。

使用应用内 Chromium 浏览器，在 1440×1000 桌面尺寸和 390×844 窄屏尺寸进行检查。

|场景|操作与观察|结果|
|---|---|---|
|页面覆盖|总览、库存、订单、入库、物流、事件、校验七页均显示对应标题及业务内容|通过|
|登录|退出后显示新版登录页，再使用演示账号进入工作台|通过|
|库存搜索|全局输入益生菌并回车，库存页筛选为对应两条批次|通过|
|仓区切换|选择 C 区，12 个非 C 区货位淡化，保留 C 区可交互|通过|
|货位详情|点击 C-04，显示实际酸奶批次、效期、在库与预留|通过|
|表单交互|创建表单添加重复商品并提交，显示同一商品请合并数量，未创建订单|通过|
|明暗主题|切换为深色后检查卡片、仓库图、图例和数值，再恢复浅色|通过|
|窄屏布局|页面视口和文档宽度均为390像素，表格在独立容器内滚动|通过|
|移动导航|展开后显示遮罩；点击库存导航进入库存并关闭侧栏|通过|
|数量守恒|运行完整校验，显示库存与事件链检查结果|通过|
|业务回归|运行现有37项领域及HTTP测试，无失败|通过|

发现并修复：自动刷新会重建页面，导致移动端已展开导航被收回。将导航状态保存为页面状态，并在导航展开时暂停周期重绘；重新验收展开与跳转行为正常。

当前验收覆盖上述 Chromium 尺寸与主要交互，没有扩展为 Safari、Firefox 或真实移动设备矩阵测试。截图位于 docs/screenshots，更新后的正式报告与交付包包含新版页面。
